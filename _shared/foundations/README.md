# Foundations

Reusable design foundations shared by both experience pipelines. These are the
rules that turn a set of liked references into an approved direction, a living
design system and an implementation that can be verified.

Read only the foundation a stage contract names. Do not load the whole folder.

| Foundation | Answers |
|---|---|
| [`taste-profile.md`](taste-profile.md) | What the user likes, why, how strongly, and how the answer is recorded without repeating questions |
| [`selection-board.md`](selection-board.md) | How references are collected, shown, selected and annotated |
| [`reference-decomposition.md`](reference-decomposition.md) | Which ten qualities a reference is decomposed into, and what each source can prove |
| [`conflict-resolution.md`](conflict-resolution.md) | How contradictory references are detected, resolved and recorded |
| [`direction-approval.md`](direction-approval.md) | What the user approves before implementation, and how approval is recorded |
| [`design-system.md`](design-system.md) | How the living design system is derived, versioned and changed |
| [`implementation-checkpoints.md`](implementation-checkpoints.md) | Where implementation stops for visual feedback, and how mid-course changes preserve approved work |
| [`responsive-and-accessibility.md`](responsive-and-accessibility.md) | The non-negotiable responsive, keyboard, focus, contrast and reduced-motion baseline |

## The three connected systems

1. **Discovery** finds and selects references and records taste. See
   `taste-profile.md` and `selection-board.md`.
2. **Direction** decomposes, resolves conflicts, proposes a concept and obtains
   approval. See `reference-decomposition.md`, `conflict-resolution.md` and
   `direction-approval.md`.
3. **Engineering** implements the approved direction, maintains the design
   system and verifies the result. See `design-system.md`,
   `implementation-checkpoints.md` and `responsive-and-accessibility.md`.

A stage may read another foundation only when its contract names it. Motion
foundations live in [`../motion/README.md`](../motion/README.md); evidence rules
live in [`../references/evidence-and-confidence.md`](../references/evidence-and-confidence.md).
