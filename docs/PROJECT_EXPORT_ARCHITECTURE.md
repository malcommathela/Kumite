# Export Architecture

## Full React project export

Include source, components, pages, styles, assets, manifest, lockfile, config, third-party notices. Exclude secrets, credentials, API keys, internal state, temp artifacts.

## Individual component export

Include component source, hooks, utilities, styles, assets, dependency metadata, usage example, license/attribution.

## Implementation status

Architecture only in Phase 1. Reuse existing file scanning/storage; packaging and exclusion logic to be built later.
