# Security Policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. If private
vulnerability reporting is enabled for the repository, use
[GitHub's private reporting form](https://github.com/malcommathela/Kumite/security/advisories/new).
Otherwise, contact a repository maintainer directly through GitHub and wait for
acknowledgement before sharing details publicly. Kumite has no dedicated
security email address at this time.
